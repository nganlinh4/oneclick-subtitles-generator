This report records the first complete run of scoring version
`osg-subtitle-metrics-2026-08-13-v2`. It is a model-selection baseline, not a
claim that one sample per cell is statistically conclusive.

This run predates the intent-scoped native exact-silence preflight added for the 1.0 release.
Its silence cohort is retained as the evidence that motivated that check; the
fingerprint below prevents these results from being confused with later runs.

Automatic translation scores are not a substitute for bilingual review. A
single review of the 24 recorded translations found no semantic inversion or

## Cohort findings

- **MP4 transport works.** Every model strictly passed the H.264/AAC MP4 case.
  The matching public Vietnamese WAV also passed 4/4, so the paired cases show
  that the production upload/generation path accepts both audio-only and video
  containers. This is a compatibility pair, not two independent utterances.
- **Silence is unsafe without a guard.** All four models invented subtitles for
  five seconds of digital silence. Outputs ranged from one short sentence to
  five numbered segments. The v2 scorer requires an empty array, so all four
  correctly score zero.
- **Korean numeric/foreign-name speech is the hardest reliability case.**
  `gemini-3.5-flash` returned a timestamp outside the production format and was
  counted as failed, with no benchmark retry. The other three outputs were
  valid but all missed the strict accuracy threshold.
- **Japanese text was recognized well by CER but often missed the timing
  envelope.** Only `gemini-3.5-flash` strictly passed that case.
- **Noise and containers were not the weak point.** The pink-noise case passed
  4/4 strictly; the low-bitrate MP3 passed 3/4 strictly; the MP4 passed 4/4.
- **Provided-line timing favors `gemini-3.1-flash-lite` in this sample.** It had
  the highest mean timing score and passed both strict gates. The similarly
  accurate `gemini-3.5-flash-lite` was about twice as slow at the median.
- **Translation has three strong candidates.** `gemini-3.5-flash`,
  `gemini-3.5-flash-lite`, and `gemini-3.6-flash` passed all protected-token and
  structural gates. The lite 3.5 model offers the strongest latency/automatic
  score balance here; a bilingual review round should precede any product
  default change.

## Product implications

1. Keep the 1.0 intent-scoped native no-audio/exact-zero preflight enabled for
   built-in speech tasks. No tested model is safe on digital silence, while an
   amplitude threshold would risk suppressing real quiet speech.
2. Keep strict timestamp schema validation. Do not silently repair the observed
   Korean timestamp failure when comparing providers.
3. Select models per task rather than from a combined score: 3.1 Flash Lite is
   the current timing baseline; 3.5 Flash Lite is the translation efficiency
   baseline; transcription remains a reliability/latency tradeoff between 3.1
   Flash Lite and 3.5 Flash.
4. Repeat this exact fingerprint before changing defaults, then add repeated
   trials and longer music/code-switching/accent cohorts in a future protocol
   rather than changing Protocol 1 fixtures in place.

The generated `summary.md`, `summary.json`, `attempts.jsonl`, and
`translation-review.md` remain under the ignored `target/` run directory so
raw model text is reviewable locally without becoming repository content.
